DATA & FILE OVERVIEW

1. File List: 

- Opsin gene expression.csv; contains RT-qPCR data for each individual and estimates of single cone predicted sensitivity index.

- Relative_OpsinExpression.csv; contains individual opsin gene expression data relative to housekeeping genes

- PlasticRate-PSI_SC.csv; contains the mean predicted sensitivity index for each day used to model the rate of plastic changes.

- Plasticity_Estimates_Full_Model.csv; contains the model estimates for the rate of plasticity and plastic capacity and their standard errors.

The "PlasticRate.Rmd" contains the code to replicate the analysis in R Software. 

Alternatively, a reader-friendly version of the code is available at GitHub repository: https://github.com/CesarBertinetti/

The "Script.html" file provides a more reader-friendly version of the code which allows to preview of the output of single steps. This is also available at https://cesarbertinetti.weebly.com/sharing.html.

The analysis was performed running R version 4.4.1 (2024-06-14) on macOS aarch64-apple-darwin20.
